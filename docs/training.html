단계별 진행

  1. 1

    예시 8개 외우기

    데이터
    직접 만든 초급 예시 8개 (hello, variables, grade, times_table, while_sum, list_stats, factorial, calculator, 2~20줄)
    방법
    전체 어휘 모델을 그대로 파인튜닝 (finetune.py, 8개를 한 배치, AdamW lr 3e-4, 300스텝). 보드용으로 내보낼 때 예시에 나온 토큰 151개 + EOS만 남겼고, 어휘에 없는 입력 토큰은 버렸다. 토큰 힐링을 넣었다.
    결과
    loss 3.2299 → 0.0354. 예시 51줄 다음 줄 정확도 0.961 → 힐링 뒤 1.000. 처음 보는 코드(test)는 정확 일치 0, 입력 토큰의 56%를 버렸다.
    다음으로
    외운 줄만 되살리고, 처음 보는 코드는 입력 절반 이상을 보지 못한다.
  2. 2

    MBPP로 범용 학습

    데이터
    MBPP 874문제 (평가용 100문제 제외, 첫 줄에 문제 설명 주석) + 예시 8개 × 8 = 938개, 88,864토큰
    방법
    원본에서 시작해 학습 전에 어휘를 1,012개로 자르고, 없는 토큰은 쪼갠다 (train_general.py --data mbpp, 300스텝). 1,500스텝으로 돌리면 200스텝 뒤부터 과적합이었다.
    결과
    test 줄 중간 정확 일치 0.056, 문법 통과 0.706 (줄 시작 0.656)
    다음으로
    최상위 줄에서 return을 내고(문법 오류), 첫 줄 주석 없이 print부터 치면 Write a function을 이어 쓴다. 학습 데이터가 전부 MBPP 함수 문제이고 모두 # Write a function ...으로 시작해서 생긴 편향이다.
  3. 실험

    모델을 키우면? (Pythia-31M)

    방법
    2단계와 같은 데이터·방법으로 Pythia-31M (d 256) 학습
    결과
    평가 loss 1.5315 (14M 1.5540). 학습 loss는 0.2554까지 내려가 학습 데이터를 외웠다. 보드용 파일은 float32 21,033,638 B로 보드에 안 들어간다.
    판단
    데이터가 8.9만 토큰일 때는 모델 크기보다 데이터 양이 병목이다. 모델은 14M으로 두고 데이터를 늘린다.
  4. 3

    데이터를 섞어 원본부터 다시 (지금 모델)

    데이터
    MBPP 974문제 전부(스크립트형 변형) + python_code_instructions_18k 표준 라이브러리 코드 12,865개 + 예시 8개 × 8 = 13,486개, 1,660,453토큰 (아래 표)
    방법
    2단계 모델 위에 이어서 학습하지 않고 원본에서 다시. 어휘를 새 데이터로 다시 고르고, MBPP 함수 편향 위에서 시작하지 않기 위해서다. 2,000스텝, 100스텝마다 dev loss를 재서 가장 낮은 시점을 저장. 예시 반복 8번(A)과 32번(B)을 비교해 A를 골랐다.
    결과
    test 줄 중간 정확 일치 0.117, 문법 통과 0.934 (줄 시작 0.919)
    A와 B
    B는 예시 외우기 1.000(A 0.549)이지만 dev 줄 중간 정확 일치가 0.123으로 A(0.158)보다 낮아, 처음 보는 코드에 더 나은 A를 보드에 올렸다.

문항은 줄 시작(다음 줄 전체를 맞히기)과 줄 중간(줄을 절반쯤 친 상태에서 나머지 맞히기) 두 가지이고, 프로그램 하나가 점수를 좌우하지 않게 프로그램당 최대 12문항이다. 지표는 정확 일치, 줄당 맞게 채워 주는 글자, 문법 통과(Python 파서로 판정)다. 생성 규칙은 보드와 같은 코드를 쓴다.
