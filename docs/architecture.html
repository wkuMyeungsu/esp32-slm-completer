esp32-slm-completer 아키텍처

ESP32-S3 보드에서 돌아가는 소형 언어 모델이 VS Code의 Python 코드를 한 줄씩 자동완성한다. 제안·수락 기록은 Supabase에 쌓인다. (2026-11-03 기준)

실행 구조

요청 하나가 지나가는 순서

  1. 확장이 커서 앞 코드(최대 1,024자)를 {"id", "prefix"}로 브리지에 보낸다.
  2. 브리지가 \r\n을 \n으로 바꾸고 Pythia 토크나이저로 자른 뒤, 보드 어휘(1,012개) id로 바꾼다. 어휘에 없는 토큰은 더 작은 토큰(최악은 1바이트)으로 쪼개고, 마지막 토큰은 떼어 힐링 문자열로 보낸다.
  3. 보드가 이전 요청과 겹치는 앞부분은 KV 캐시로 건너뛰고, 나머지를 계산해 한 줄을 생성한다. 힐링 문자열과 맞는 토큰만 고르다가, 줄이 끝나거나 같은 조각이 3번 반복되거나 32토큰이 되면 멈춘다.
  4. 보드가 완성과 멈춘 이유, 생성 시간, 최소 남은 힙을 돌려준다.
  5. 브리지가 결과를 확장에 넘기고, 문법 검사 결과와 함께 logs/rows.jsonl에 남긴다. 10초마다 Supabase로 보낸다.
  6. 확장이 회색 제안을 띄우면 shown, 사용자가 Tab으로 받으면 accept를 브리지에 보낸다.
