# 테스트 세트 출처와 라이선스

`dev.txt`, `test.txt`는 `train/build_testsets.py`가 아래 저장소의 교재 예제·모범 답안에서 규칙에 맞는 것을 골라 정리한 코드다. 바꾼 점: 탭을 공백 4칸으로, 줄 끝 공백 제거, Think Python 파일 머리의 저작권 docstring과 `from __future__ import ...` 줄 삭제. 학습에는 쓰지 않는다. 각 프로그램의 원래 경로는 `#### <출처>/<경로>` 줄에 있다.
